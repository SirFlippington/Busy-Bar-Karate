# Original assets — Karate 1.5.2

All sprites, animation frames, backgrounds, music and sound effects shipped in this version are original assets generated by `generate_assets.py` for this project. They are licensed under the repository MIT License.

Characters are drawn from geometric pixel primitives at the display resolution. The background is an original moonlit rooftop. Animation clips assemble these drawings along game-specific motion paths. Audio is synthesized from oscillator tones, deterministic noise and a newly composed note sequence. No external image, sprite sheet, recording or melody is loaded by the generator.

The original Nintendo/Irem-derived sprites and the previously supplied background and recordings have been removed from the current app tree. They remain in old Git history/releases, which are not the source commit submitted for this version.

Regenerate all media with Python 3, Pillow and NumPy: `python3 generate_assets.py`.

Version 1.5.1 redraws each character with distinct proportions, costume and stance. Punch and kick transitions articulate the attacking limb without shifting the whole body.

Version 1.5.2 uses generate_audio.py for the original 180 BPM score and formant-synthesized martial-arts yells, swishes and impacts. Audio uses sample-and-hold and amplitude quantization for a bitcrushed sound; no voice recordings are used.
